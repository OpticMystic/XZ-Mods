# Static Surfer artwork

Artwork and character references supplied by VJ OpticMystic from E:/Game INspiration. These are private prototype assets, not a public asset release. The native engine is MIT; that does not relicense the artist's images.

Three original environments are packed as400x188 RGB565 textures: mushroom/skull jungle, purple tentacle landscape, and chrome-face tunnel. catalog.json records original paths and hashes. Display-format resizing leaves the originals untouched.

The glitch cat and birthday-hat cow are transparent game-sprite adaptations made with the built-in image_gen tool using the owner's original images as references. Native96x96 RGB565 plus alpha copies live here and are embedded in glyph_art.c; building the game needs no external image files or decoder. Full generated assets remain in E:/Codex/xz-prism-pilgrim-20261003/art.

Cat prompt: faithful glowing-eyed black glitch cat from reference8, right-facing airborne pounce, pointed ears, cyan/violet edge light, curved glitch tail, true transparent background, readable at60px, no environment/text/frame.

Cow prompt: faithful favorite cream/tan cow from reference26, wide ears and dark nose, colorful sparkly cone birthday hat with pompom, full-body three-quarter floating pose, all four hooves visible, cyan/purple rim light, true transparent background, readable at80px, no saucer/beam/environment/text. The game draws the UFO, beam and waveform-reactive confetti.
