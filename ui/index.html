    Set up Live Streamer

    1. Find the XZ

    Connect this computer and the XZ to the same network, for example the same router or a network cable between them. XZ Mods looks for the XZ as soon as this opens.

    Network details

    The address is an IPv4 address such as 169.254.168.59. Finding the XZ uses UDP port 50006 and the screen uses TCP port 50010; a firewall must allow both on this network.

    2. Update the USB loader if asked

    Older USB loaders have no screen service. If this wizard says so, update the loader on the USB page, then power cycle the XZ with both decks stopped. This wizard never restarts the XZ.

    3. Connect

    The first picture from the XZ confirms the connection. Watching does not take over the XZ display, and OBS reuses the same pictures.

    Looking for your XZ…

    Send the installed mod runtime to XZs on your local network. Each XZ verifies the signed update, saves it on USB, and activates it at the next boot.

    A USB built with Keep this version on the USB turned on ignores network updates. To let it take them, turn that option off, save the mod version, then update that USB's loader.

    Set up XZ network updates

    1. Prepare or update the USB loader once to add network-update support.

    2. Choose this computer's adapter connected to the XZ network.

    3. On the XZ, open MODS → Extras → Network updates, check for an update, then download it. Power cycle when you are ready to activate it.

    The update server stays on your selected network. Use Cancel below to stop it.

    This updates XZ Mods and the game engine. It preserves music and the original USB recovery loader.

              XZ Mods

              Version 0.5.0-preview.22.12

              Made by OpticMystic · for the Pioneer DJ XDJ-XZ on firmware 1.26

              XZ Mods adds stems, four decks, a MODS menu, DJ profiles, themes and games to the XDJ-XZ. It starts from a USB stick, and this app prepares that USB and makes stems for your tracks.

              OpticMystic builds tools for DJs and VJs and publishes them on GitHub.

              Prepare for repair
              1. Close Rekordbox
              Save your work in Rekordbox, then quit it. While it is open it can write to the USB library.
              2. Check again
              XZ Mods reads the library again and confirms Rekordbox has closed.
              

              Undo this repair?
              The disconnected playback history comes back exactly as it was. Only the Device Library database is put back. Your music and prepared stems stay in place.
              

              Set up mod versions
              1. Find mod versions on this computer
              

              2. Import a build (optional)
              Choose a prepared XZ Mods resources folder, or a full XZ Mods app folder that contains one. XZ Mods finds the build and checks every file hash before adding it. Imported builds are not hardware-verified.
              

              3. Choose and save
              Pick the version in Tools › XZ Mods version and save it. Nothing is written to a USB until you build or update one.
              

              Adjust USB settings for this version
              XZ Mods first saves a copy of the current settings file on the USB. If the loader write fails, the original settings go back. Your music, library and stems are not changed.
