    What can be shared

    The builder, original mod code and applicable open-source components can be distributed with their required notices and source obligations. Device firmware, boot keys and generated personal boot images are excluded from the public package.

    Selected model weights

    • Smule Windowed RoFormer: original MIT grant covers code and checkpoints.
    • Open-Unmix UMX-HQ: original MIT grant covers the selected weights.
    • Demucs research-only weights, non-commercial UMXL and unclear checkpoint mirrors are not offered as public presets.

    MPL, LGPL and OFL components retain their licenses. “Free to use” does not remove notice and source obligations.

    Release qualification

    This preview does not claim the full upstream feature set is complete.

    • Native inline UI acceptance
    • Fresh boot and two-deck qualification
