Prepare a new USB or update the loader on one you already use.

Update an existing loader

Choose the USB drive containing autoexec.bin. XZ Mods keeps a backup of the old loader. Music and saved settings stay in place.

Prepare a new USB

Choose your USB drive to add the XZ Mods loader. If it already has a loader, use the update option above.

The first run downloads firmware and boot support. Later runs reuse the verified copies. This app does not format your USB. Test the loader on the XZ before using it in a set.

Prepare from a downloaded firmware file

Choose an official XDJ-XZ 1.26 firmware file and a destination. If you choose a folder on this PC, copy the resulting autoexec.bin to your USB afterward.

Edit the settings saved on your USB. The XZ loads them when the loader starts.

Choose the settings USB

Select the USB or prepared folder that contains VJ.Tools/XZ-Mods.cfg. If your loader uses a separate settings partition, select that partition here.

These options match the loader bundled with this app. Update an older loader to use the newer options.

We recommend OverCue Desktop for preparing stems. XZ Mods reads its files directly. You can also generate or import stems below.

Build stems in XZ Mods

Beta

XZ Mods can also separate tracks on this PC. It saves the results in CDJMODS on your USB and keeps any stems already made by OverCue.

Export the track with Rekordbox first. It must be a 44.1 kHz stereo WAV or FLAC file in the USB's Contents folder. Processing can take a while. This feature is still in testing, so check each track on the XZ before using it in a set.
