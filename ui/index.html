    Reading mod versions…

    Update an existing loader

    Choose the USB drive containing autoexec.bin. XZ Mods keeps a backup of the old loader. Music and saved settings stay in place.

    Prepare a new USB

    Choose your USB drive to add the XZ Mods loader. If it already has a loader, use the update option above.

    Setup downloads firmware, boot support, Doom shareware, Chex Quest and Freedoom Phase 2. Later runs reuse verified downloads. This app does not format your USB. Test the loader on the XZ before using it in a set.

    Prepare from a downloaded firmware file

    Choose an official XDJ-XZ 1.26 firmware file and a destination. If you choose a folder on this computer, copy the resulting autoexec.bin to your USB afterward.

    Game downloads

    Set up games on an existing USB

    Download and verify the free game files, keep their license notices, and copy them to your USB. Existing files stay in place. Use this to retry any download that failed during loader setup.

    Doom shareware

    The original free first episode. The game engine also runs classic Doom II data when you supply your own licensed WAD.

    Chex Quest

    The original promotional game, with its compatibility patch. Game data is downloaded from the original community distribution when you choose it.

    Freedoom Phase 2

    A complete free base game compatible with Doom II mods, with different artwork. It is included in USB setup and appears in Doom's WAD picker. Full commercial Doom and Doom II require your own licensed WAD.

    Your own WADs

    Put compatible base games and add-ons in a WADS folder on either USB. Choose a base game first, then an optional add-on in the XZ's USB WAD loader.

    GZDoom-format maps and PK3 files do not run on the XZ. Downloading game data does not update the XZ loader.

    Set up Live Streamer

    1. Find the XZ

    Connect this computer and the XZ to the same network, for example the same router or a network cable between them. XZ Mods looks for the XZ as soon as this opens.

    Network details

    The address is an IPv4 address such as 169.254.168.59. Finding the XZ uses UDP port 50006 and the screen uses TCP port 50010; a firewall must allow both on this network.

    2. Update the USB loader if asked

    Older USB loaders have no screen service. If this wizard says so, update the loader in Set up USB, then power cycle the XZ with both decks stopped. This wizard never restarts the XZ.

    3. Connect

    The first picture from the XZ confirms the connection. Watching does not take over the XZ display, and OBS reuses the same pictures.

    Looking for your XZ…

    Send the installed mod runtime to XZs on your local network. Each XZ verifies the signed update, saves it on USB, and activates it at the next boot.

    A USB built with Keep this version on the USB turned on ignores network updates. To let it take them, turn that option off, save the mod version, then update that USB's loader.

    Set up XZ network updates

    1. Prepare or update the USB loader once to add network-update support.

    2. Choose this computer's adapter connected to the XZ network.

    3. On the XZ, open MODS → Extras → Network updates, check for an update, then download it. Power cycle when you are ready to activate it.

    The update server stays on your selected network. Use Cancel below to stop it.

    This updates XZ Mods and the game engine. It preserves music and the original USB recovery loader.
