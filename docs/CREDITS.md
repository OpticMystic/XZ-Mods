# XZ Mods credits and software notices

XZ Mods is created by **VJ OpticMystic**. Thank you for trying it, sharing useful
reports, and helping make more of the equipment we own.

- [XZMods.com](https://xzmods.com/) has project information.
- [Instagram @opticmysticvj](https://www.instagram.com/opticmysticvj) has updates
  and other projects. This account is linked from the
  [official OpticMystic website](https://opticmystic.live/).
- [OpticMystic.live](https://opticmystic.live/) has live VJ performances,

  source. Use the source archive and commit identified by your particular build
  when you need to reproduce that build.

This attribution identifies that published work, without claiming that one
person originated every technique used across the community.

**nsaintot and the cdj3k-mods contributors.** Thanks for

## Read the notices for your build

The desktop app's **About > Open license notices** action opens its local `licenses`
folder. Keep that folder and the corresponding source with redistributed
packages. This page is a readable index; it does not replace any license text,
copyright notice, source requirement, or the terms of an individual component.

The native resource staging set inspected on October 23, 2026 contains these
notices. The final desktop package can include additional dependencies.

| Component | Notice supplied with the package |
| --- | --- |
| XZ Mods and XZ toolkit | `XZ-Mods-MIT.txt`, `XZ-Toolkit-MIT.txt` |
| cdj3k-mods-derived work | `cdj3k-mods-LICENSE-MIT`, `cdj3k-mods-LICENSE-APACHE` |
| MPL-covered receiver source | `Mozilla-MPL-2.0.txt`; retain the receiver's original notice and corresponding source |
| Doom | `Doom-GPL-2.0.txt`; retain corresponding source and applicable build material |
| Barlow font, The Barlow Project Authors | `Barlow-OFL.txt`; font source and copyright accompany redistribution |
| miniz and jsmn | `miniz-MIT.txt`, `jsmn-MIT.txt` |
| SHA-256 implementation | `sha256-public-domain.txt` |
| Monocypher | `Monocypher-BSD-CC0.txt` |
| Python | `Python-PSF.txt` |
| OpenSSL | `OpenSSL-4.0.0-APACHE.txt` |

| Included model notices | `umxhq-mit.txt`, `demucs-mit.txt`, `msst-mit.txt`, `kj-melband-mit.txt` |
| Quad helpers and network client | `Quad-helpers-MIT.txt`, `xz-network-client-source.tar.gz` |

The Windows resource builder also gathers installed dependency notices for
pycdlib, cryptography, cffi, and PyInstaller. It copies pycdlib's Python source
for its LGPL obligations. That desktop dependency set is separate from the
native staging set above. Bundled versions and their actual notices determine
the terms; a general MIT label for XZ Mods does not relicense those components.

The source tree also retains the original dr_libs, stb, and Project Nayuki
notices. Preserve them when distributing code or binaries that include those
components. The About QR matrices are precomputed; the About renderer does not
link a new QR library. Its logo is the existing XZ Mods asset.
